# Current Learning Focus

## Goal

Be able to express daily events and feelings in simple English after thinking.

Immediate goal:

- Understand basic patterns.
- Speak simple sentences with support.
- Gradually move from supported output to independent output.

## Practice Method

Every day:

1. ChatGPT asks about today's events in Japanese.
2. ChatGPT creates English sentences using the 30 patterns.
3. Read the sentences aloud.
4. Check pronunciation.
5. Create personal sentences.
6. Record the result.
