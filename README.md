# English Learning Study Repository

## Purpose

This repository manages an English learning workflow focused on daily speaking practice.

The goal is not perfect English accuracy first. The goal is to become able to express daily thoughts using simple English patterns.

## Learning Method

- Practice 30 basic sentence patterns every day.
- ChatGPT provides input based on today's real events.
- Practice consists of:
  - Listening
  - Shadowing / reading aloud
  - Pronunciation checking
  - Creating personal sentences
  - Speaking about personal experiences

## Structure

- `patterns/` : Core sentence patterns
- `profile/` : Personal topics used for conversation
- `logs/` : Daily practice records
- `progress/` : Learning status
- `templates/` : Recording templates
